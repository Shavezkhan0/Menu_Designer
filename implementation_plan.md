# AI-Powered Restaurant Menu Designer

## Overview

Build a self-contained, AI-powered Restaurant Menu Designer as a new route within the existing Next.js monorepo (`apps/frontend`). When a restaurant owner selects a category (e.g., Cocktails, Burgers, Pizza), the menu **auto-generates** instantly with beautiful layouts. The owner can customize branding (logo, background, colors, theme) and use the **Grok API (xAI)** to generate professional item descriptions and AI backgrounds — no data upload required.

### API Routes (Grok Integration)

#### `POST /api/grok/generate-description`
- Input: `{ itemName, category, style: 'premium'|'short'|'ingredients' }`
- Output: AI-generated description string
- Uses: `xai-grok-3-mini` or `xai-grok-3`

#### `POST /api/grok/generate-background`
- Input: `{ prompt: string }`
- Output: Image URL or base64 image
- Uses: xAI image generation API (`grok-2-image`)

#### `POST /api/grok/generate-theme`
- Input: `{ style: string }` e.g. "luxury cocktail bar"
- Output: `{ primaryColor, accentColor, bgColor, font, cardStyle }`
- Uses: `xai-grok-3-mini` with structured JSON output

## Visual Design System

### Design Philosophy
The UI must feel like a **commercial SaaS product** — the kind of polished, intentional interface you'd find at Stripe, Vercel, Linear, or Clerk. Every pixel is purposeful. Nothing looks auto-generated.

### Design Inspirations
| Source | What We Borrow |
|---|---|
| **Linear** | Keyboard-driven sidebar, crisp mono-spaced labels, dense information |
| **Vercel** | Dark-first, stark contrast, clean empty states, pill badges |
| **Stripe** | Card grid layouts, subtle gradients under charts, section dividers |
| **Framer** | Real-time preview canvas, device toggle, smooth panel transitions |
| **Figma** | Sidebar panel groups, icon-labeled sections, property editors |
| **Clerk Dashboard** | Sidebar navigation feel, two-tone layout (dark left / light right) |
| **Raycast** | Command-palette-style AI prompts, keyboard shortcut hints |
| **Arc Browser** | Soft color system, sidebar tabs with emoji/icon labels |

### Component-Level Design Rules

| Component | Design Rule |
|---|---|
| **Sidebar sections** | Collapsible accordion with animated chevron, subtle glass bg on open |
| **Category pills** | Emoji + label, gradient border on selected, smooth scale-up on click |
| **Color pickers** | Swatch grid + hex input, not browser default |
| **AI prompt area** | Styled like Raycast command palette — dark, rounded, with shimmer while loading |
| **Menu item cards** | Glass effect, price in monospace, badges for "New"/"Signature", hover lift |
| **Device toggle** | Three icons (monitor/tablet/phone) with animated underline indicator |
| **Layout selector** | Visual thumbnail previews (not just text labels) |
| **Buttons** | Primary: violet gradient with glow shadow. Secondary: ghost with border. |
| **Inputs** | Dark bg, subtle border, focus ring in accent color |
| **Section labels** | 11px uppercase, letter-spacing 0.1em, muted color — like Linear |

### What We Explicitly Avoid

| ❌ Avoid | ✅ Instead |
|---|---|
| Generic AI dashboard grids | Intentional, branded layout with personality |
| Plain Tailwind utility soup | Named design tokens, consistent scale |
| Bootstrap-style flat cards | Layered glass cards with depth and shadow |
| Standard `<button>` styling | Gradient primary, ghost secondary, icon-only tertiary |
| Plain table rows | Animated card grid with staggered entry |
| Default browser form inputs | Custom dark-themed inputs with focus glow |
